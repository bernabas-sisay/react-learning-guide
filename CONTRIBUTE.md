## 🚀 How to Contribute

### Step 1: Fork the Repository
```bash
# Click "Fork" button on GitHub
```

### Step 2: Clone Your Fork
```bash
git clone https://github.com/YOUR_USERNAME/react-learning-guide.git
cd react-learning-guide
```

### Step 3: Create a Branch
```bash
git checkout -b feature/your-feature-name
# Or for fixes:
git checkout -b fix/what-you-fixed
```

### Step 4: Make Your Changes
- Edit files
- Add new files
- Improve content

### Step 5: Commit Your Changes
```bash
git add .
git commit -m "Clear description of what you changed"
```

### Step 6: Push to Your Fork
```bash
git push origin feature/your-feature-name
```

### Step 7: Create a Pull Request
1. Go to the original repository
2. Click "New Pull Request"
3. Select your branch
4. Describe your changes
5. Submit!

## ✅ Contribution Guidelines

### Before You Start
- [ ] Check if an issue already exists
- [ ] Read the existing content
- [ ] Follow the established style
- [ ] Test your changes

### When Contributing

**For Code Examples:**
```jsx
// ✅ Good: Clear, well-commented
function Example() {
  const [count, setCount] = useState(0);
  
  // Handle click
  const handleClick = () => setCount(count + 1);
  
  return <button onClick={handleClick}>{count}</button>;
}
```

**For Writing:**
- Use simple, clear language
- Explain concepts step-by-step
- Include analogies and examples
- Use emoji appropriately 😊
- Keep paragraphs short

**For Files:**
- Use clear file names
- Follow folder structure
- Add comments in code
- Update README in parent folder

### Style & Tone

- ✅ Beginner-friendly
- ✅ Encouraging and positive
- ✅ Use examples extensively
- ✅ Break down complex ideas
- ✅ Use emoji to add personality
- ❌ Don't be condescending
- ❌ Don't use advanced terminology without explaining
- ❌ Don't skip important details

## 🎯 Contributor Code of Conduct

We're building a friendly learning community!

✅ **Be respectful** - Treat everyone with kindness
✅ **Be helpful** - Welcome beginners
✅ **Be constructive** - Suggest improvements, not criticism
✅ **Be honest** - Admit mistakes, learn from them
✅ **Be inclusive** - Support diverse perspectives

❌ **Don't be rude** - No harsh language or dismissal
