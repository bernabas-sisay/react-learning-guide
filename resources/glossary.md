# 📖 React Glossary - Key Terms Explained

Quick reference for React and web development terminology.

---

## A

**API** - Application Programming Interface. A way for applications to communicate.

**Async/Await** - Modern way to handle asynchronous operations in JavaScript.

---

## C

**Component** - Reusable piece of UI that returns JSX.

**Controlled Component** - Component where React controls the form input value.

**CSS-in-JS** - Writing CSS inside JavaScript files.

---

## D

**DOM** - Document Object Model. Tree structure of HTML elements.

**Destructuring** - Extracting values from objects/arrays into variables.

```jsx
const { name, age } = user; // Destructuring object
```

---

## E

**Event Handling** - Responding to user interactions (clicks, typing, etc.).

**Effect** - Side effect. Anything that happens outside React's rendering (fetching, subscriptions).

---

## F

**Fragment** - Wrapper that doesn't create a DOM node. Use `<>` or `<React.Fragment>`.

**Functional Component** - Component written as a JavaScript function.

---

## H

**Hook** - Function that lets you use React features in functional components.

**Higher-Order Component (HOC)** - Advanced pattern for reusing component logic.

---

## J

**JSX** - JavaScript XML. HTML-like syntax in JavaScript.

---

## K

**Key** - Special string attribute for identifying elements in lists.

---

## L

**Lazy Loading** - Loading code/components only when needed.

**Lifting State** - Moving state up to a common parent component.

---

## M

**Middleware** - Function that intercepts and processes requests/actions.

**Mount** - When a component is added to the DOM.

---

## P

**Props** - Properties. Data passed from parent to child component.

**Prop Drilling** - Passing props through many levels of components.

---

## R

**Render** - Process of displaying components on screen.

**Ref** - Reference to a DOM element or class component instance.

**Reducer** - Function that determines how state changes based on actions.

---

## S

**State** - Data that a component manages and can change.

**State Management** - Organizing and managing application state.

**Side Effect** - Any operation that affects something outside the component (API call, DOM manipulation).

---

## U

**Uncontrolled Component** - Component where the DOM manages the form value.

**Unmount** - When a component is removed from the DOM.

---

## V

**Virtual DOM** - Lightweight representation of the real DOM used by React.

---

## Common Abbreviations

- **JSX** - JavaScript XML
- **DOM** - Document Object Model
- **API** - Application Programming Interface
- **HTTP** - HyperText Transfer Protocol
- **JSON** - JavaScript Object Notation
- **CRUD** - Create, Read, Update, Delete
- **SPA** - Single Page Application
- **CSR** - Client-Side Rendering
- **SSR** - Server-Side Rendering

---
